# PulsHealth 2.3 release copy

Prepared for 2.3 (29). This is preparation, not an upload or submission record.

## What’s New

Clearer first sync
Review your data types and history on the Sync screen before starting your first database sync.

Better medication exports
Medication doses now include readable names when available and consistent medication identifiers within this app installation.

More efficient workout syncing
Unchanged workout streams that your database has already received are skipped on subsequent syncs.

Reliability improvements
Fixes a crash when changing aggregate options and protects first-sync setup when replaying onboarding.

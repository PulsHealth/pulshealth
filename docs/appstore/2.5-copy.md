# PulsHealth 2.5 release copy

Uploaded as 2.5 (34) to internal TestFlight on 2026-11-16. No App Store review submission or public release. See README.md for the delivery record.

## What’s New

Connections in one place
Connect your own server or PulsHealth, give connections optional names, and manage sync settings for each connection.

Data requests
Review and share selected health data through one-time or ongoing requests. Manage sharing from Connections.

Simpler exports and settings
Add data to a one-time export from Explore with fewer distractions, and find account, performance and help options in reorganized Settings.
